# tools/archive — công cụ chạy một lần, đã xong việc

Giữ lại để tra cứu. Không chạy trong CI hay quy trình thường ngày.

| File | Việc đã làm |
|---|---|
| `extract_keys.php` | Trích tông gốc từ MusicXML vào CSDL (L0-11) |
| `fetch_sheet.py`, `batch_fetch_all.py` | Tải MusicXML Thánh Ca từ nguồn ngoài lúc dựng thư viện ban đầu |

Đường dẫn trong script đã chỉnh cho vị trí mới (`tools/archive/`).
